# Security policy

Penge is preparing for an initial release. The current reviewed main branch is maintained without a long-term support guarantee.

Report suspected vulnerabilities privately to the repository owner through private GitHub security reporting when enabled, or an existing private channel. A dedicated public security contact must be chosen before public release. Never open a public issue containing credentials, user data or reset/invitation URLs.

Include affected source version, synthetic reproduction, expected/actual behavior and impact. Do not test against another person's installation without permission. Do not access, modify or disclose others' data.

See docs/SECURITY-AUDIT.md for scope and remaining risks. This first-party assessment and automated checks are not independent assurance or a claim of complete security.
